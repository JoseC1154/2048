History & instructions

Action history

    Tap to select · double tap to flip · hold a block to select its touching group · drag for grid movement. The yellow ACTIVE badge marks the tile moved by both keyboard arrows and arrow buttons. Tap, drag, or Tab to a tile to make it active. Green outlines mark notes selected for a chord; joined blocks move together. The flip preview shows the active note’s result and cost. A shift of 0 or ±12 keeps the same note but still spends 2 MP and advances the shift. Each cell traveled costs MP. At zero energy, a playable chord can still be played for free. Otherwise, if space is available, a charged copy of an existing note spawns in a random empty cell and grants 3 MP; completing any valid major or minor chord fully restores 18 MP. Beginner has one board-lock rescue; Advanced has none. The semitone register previews three upcoming shifts. Each successful move or flip advances exactly one preview step; a flip uses the current shift before advancing. Undo restores the previous preview. JOIN requires edge contact. Play any connected major or minor triad to score. Each played chord is replaced with three new random notes in the cleared cells. The game continues until the survival rules end it.
